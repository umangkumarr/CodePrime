## Problem

Given integers `a`, `n` and `m` with $n \ge 0$ and $m \ge 1$, compute $a^n \bmod m$.

```txt
Input:  a = 2, n = 3, m = 3
Output: 2
Explanation: 2^3 = 8 and 8 mod 3 = 2.

Input:  a = 3, n = 200, m = 1000000007
Output: 136318165
```

$3^{200}$ has 96 digits, far beyond any built-in integer type, yet the answer is below $m$. The trick is to never build the full power.

## Idea

This is [binary exponentiation](/docs/dsa/number-theory/exponentiation/) with one change: reduce modulo $m$ after **every** multiplication. That is allowed because taking the remainder commutes with multiplication:

$$(x \cdot y) \bmod m = \big((x \bmod m) \cdot (y \bmod m)\big) \bmod m$$

So every intermediate value stays in $[0, m)$, and the final result is the same as if we had computed $a^n$ exactly and reduced once at the end.

## Algorithm

1. Reduce the base first: `a = a mod m` (making it non-negative if `a` was negative).
2. Set `ans = 1 mod m`.
3. While `n > 0`:
   - if the lowest bit of `n` is 1, set `ans = (ans * a) mod m`;
   - set `a = (a * a) mod m`;
   - set `n = n >> 1`.
4. Return `ans`.

## Complexity

- **Time:** $O(\log n)$ multiplications and remainders.
- **Space:** $O(1)$.

## Edge cases

- **Overflow in the product:** both factors are below $m$, so a product is below $m^2$. With $m$ up to about $3 \cdot 10^9$ that fits in a 64-bit `long long` ($m^2 < 9.2 \times 10^{18}$). Common moduli such as $10^9 + 7$ are well inside this. Doing the multiplication in 32-bit `int` would overflow for any $m$ above about 46,341.
- **`m = 1`:** every number is 0 modulo 1, so the answer must be 0. Starting from `ans = 1 % m` handles this, including when `n = 0`.
- **`a` larger than `m` or negative:** reducing it first keeps the first product in range; the `+ m` makes a negative remainder non-negative in C++.

## Code

<Tabs syncKey="lang">
<TabItem label="C++">

```cpp
#include <iostream>
using namespace std;

// (a^n) mod m for n >= 0 and 1 <= m <= ~3e9.
long long modPow(long long a, long long n, long long m) {
    a = (a % m + m) % m;    // bring the base into [0, m)
    long long ans = 1 % m;  // 0 when m == 1
    while (n > 0) {
        if (n & 1) ans = ans * a % m;
        a = a * a % m;
        n >>= 1;
    }
    return ans;
}

int main() {
    cout << modPow(2, 3, 3) << '\n';            // 2
    cout << modPow(3, 200, 1000000007) << '\n'; // 136318165
}
```

```py
def mod_pow(a, n, m):
    """(a ** n) % m for n >= 0 and m >= 1, by binary exponentiation."""
    a %= m          # Python's % is already non-negative for m > 0
    ans = 1 % m     # 0 when m == 1
    while n > 0:
        if n & 1:
            ans = ans * a % m
        a = a * a % m
        n >>= 1
    return ans


print(mod_pow(2, 3, 3))             # 2
print(mod_pow(3, 200, 1000000007))  # 136318165
```

Python also has this built in: `pow(a, n, m)`.
