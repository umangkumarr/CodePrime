## Problem

Given a number `n`, find the length of the longest run of consecutive 1s in its binary representation. ([GeeksforGeeks: Longest Consecutive 1's](https://www.geeksforgeeks.org/problems/longest-consecutive-1s-1587115620/1))

```txt
Input:  n = 14
Output: 3
Explanation: 14 is 1110 in binary; the longest run of 1s is 111.

Input:  n = 222
Output: 4
Explanation: 222 is 11011110 in binary; the longest run of 1s is 1111.
```

**Constraints:** $1 \le n \le 10^9$

## Idea

AND a number with a copy of itself shifted one place. A bit survives only if **it and its neighbour** are both 1, so every run of 1s loses exactly one bit, and a run of length 1 disappears:

```txt
  x            = 1 1 0 1 1 1 1 0     (222)
  x >> 1       = 0 1 1 0 1 1 1 1
  x & (x >> 1) = 0 1 0 0 1 1 1 0     runs of 2 and 4 became runs of 1 and 3
```

Repeat until nothing is left. A run of length $L$ survives exactly $L - 1$ rounds and vanishes on the $L$-th, so **the number of rounds equals the longest run**.

## Algorithm

1. Set `count = 0`.
2. While `n` is not 0: replace `n` with `n & (n >> 1)` and add 1 to `count`.
3. Return `count`.

Trace for `n = 222`: `11011110 → 01001110 → 00000110 → 00000010 → 0`, four rounds, so the answer is 4.

## Complexity

- **Time:** $O(L)$ where $L$ is the answer. Since $L \le \lfloor \log_2 n \rfloor + 1$, this is at most $O(\log n)$: 30 rounds for $n \le 10^9$.
- **Space:** $O(1)$.

## Edge cases

- **Shifting direction:** `n & (n << 1)` works equally well, but on a signed type it can push 1s into the sign bit. The C++ version takes an `unsigned` value, so the right shift always brings in 0s and the loop always ends; with a signed negative number `n >> 1` would copy the sign bit forever.
- **`n = 0`:** the loop never runs and the answer is 0.

## Code

<Tabs syncKey="lang">
<TabItem label="C++">

```cpp
#include <iostream>
using namespace std;

int maxConsecutiveOnes(unsigned int n) {
    int count = 0;
    while (n) {
        n &= n >> 1;  // every run of 1s loses one bit
        count++;
    }
    return count;
}

int main() {
    cout << maxConsecutiveOnes(14) << '\n';   // 3
    cout << maxConsecutiveOnes(222) << '\n';  // 4
    return 0;
}
```

def max_consecutive_ones(n):
    count = 0

    return count
